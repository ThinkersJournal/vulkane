---
**`vulkane-msl-emit` lowers `Reduce(Sum)`, `Reduce(Max)` and `Reduce(Min)` over an `F32` kernel's subgroup (board 506 A float ruling, pm-kernels 2026-11-27).** Sum is `simd_sum`; Max and Min are `simd_max` / `simd_min` wrapped in `select(.., NAN, simd_any(isnan(v)))`, because the bare functions IGNORE a NaN operand (measured on the hosted macOS paravirtual device, vulkane#189 run 45972534688) and KISS-OPS-6.11-0002 requires a float reduce(max|min) to propagate NaN. The `Dialect` hook is the existing `subgroup_collective`; the float dialect says `subgroup_collectives()` for `F32` only, so half and bfloat kernels stay declined by name. `Prod`, `Mean`, shuffles, votes, broadcasts and scans stay declined (unmeasured or outside the ruling); the refusal text names the three that are lowered.

**Tests and measurements.** Text pins for the three spellings and the declines; five vacuity mutants (NaN select removed from Max, from Min, Max spelled as Min, half collectives enabled, Prod accepted as a sum), each caught by name. `vulkane-test-support::float_collective_kernel` holds the kernel, an eight-subgroup input (finite; NaN in the first, last and a middle lane; all NaN; NaN with +inf; NaN with both infinities; signed zeros), the oracle (Unpopped's CPU oracle, which propagates NaN) and the comparator: Max and Min exact-byte with a NaN lane required to give NaN, the +-0 cells excluded (KISS does not pin them), Sum under a tolerance that is OURS, NOT KISS's (the clauses KISS-OPS-6.0-0004, 6.17-0005 and 6.17-0008 state no bound): `(n-1) * 2^-24 * sum|x_i|`. The hosted-device cases include a vacuity mutant, the lowered Max kernel with the select removed, which the comparator must reject. **Limits:** measured on the hosted paravirtual device, not Apple hardware; safe math only, fast-math not measured (a kernel compiled with fast-math may differ).
