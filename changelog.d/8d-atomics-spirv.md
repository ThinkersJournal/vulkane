kind: SPIR-V kernels lower 32-bit integer atomics (ROADMAP 8d, first slice)
---
`SpirV.lower_kernel` lowers `Stmt::AtomicRmw` (`Add`, `Min`, `Max`, `And`, `Or`, `Xor`, `Exchange`; signed or unsigned form from the compute dtype) and `Stmt::AtomicCas` on a storage-buffer or workgroup-array element at subgroup, block or device scope. `Relaxed` carries no ordering bits; acquire, release and acq-rel/seq-cst add the pointer's memory class (seq-cst collapses to acquire-release, as the fence does). A `Cluster` scope is a typed decline; an atomic on a `Private` array is refused by `check_kernel`, with a matching guard in the emitter. Tests: unit tests for the instructions and a racy-control module; a live device test where 1024 contended adds from 16 workgroups sum exactly, the unsigned minimum and exactly-one compare-exchange winner hold, and the non-atomic control lost updates (reached 1 of 1024 on the Windows device; reported, not asserted). Not done: GLSL, WGSL and HLSL arms, 64-bit and float atomics (capability-gated).
