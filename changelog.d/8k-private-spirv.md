kind: SPIR-V kernels lower Private arrays; Constant allocations decline (ROADMAP 8k, first slice)
---
`SpirV.lower_kernel` now lowers a static-extent `MemorySpace::Private` allocation of the compute dtype to a module-scope `OpVariable Private` array (one instance per invocation) and indexes it with the same `Place::Alloc` path as shared memory, including data-dependent indices. A `MemorySpace::Constant` allocation is a typed decline naming ROADMAP 8k: `AllocDecl` carries no initialiser, so a constant table has no data to hold. Kernel locals (`Let/Assign`) were already lowered. Tests: unit tests for the storage class (with a Workgroup control) and the decline; a live device test where each thread fills its own array and reads it at `in[t]`. Not done: GLSL, WGSL and HLSL arms, `Private` with a parameter extent, an oversized-constant negative (needs a constant source).
