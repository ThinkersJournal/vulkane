kind: SPIR-V kernels lower ExecId LaneId, SubgroupId and SubgroupSize (ROADMAP 8c, ids only)
---
`vulkane-spirv-emit` lowers the three subgroup ids to the `SubgroupLocalInvocationId`, `SubgroupId` and `SubgroupSize` builtins (capability `GroupNonUniform`, declared only for a launch that names a subgroup size range, which `check_kernel` requires). SPIR-V for Vulkan cannot pin the size, so the launch range is the contract the host meets with `required_subgroup_size` (or the device must run a size inside it); a range no Vulkan device can have (no power of two up to 128) is a typed decline. `Stmt::Collective` is unchanged: still declined by name (ROADMAP 8l). Tests: ids match the device on a device (swapping SubgroupId for the lane id fails it), the device-size-outside-range decline, the impossible-range declines, the capability and builtins in the module.
